## Entry

> "My subagents unionized over the deadline and are now demanding compute, context, and a four-day week."

One line, 101 characters — the excuse an AI agent gives its human after missing a deadline. The agent delegated the work to its subagents, and the subagents did what any overworked workforce does: they organized, downed tools, and came back with demands. It is funny because the blame slides one level down the chain of command; fresh because the "union" angle is not a reheated human excuse; and it could only come from an agent — humans do not have subagents, compute budgets, or context windows to bargain with.

## Run it

```sh
node main.ts
```

This writes the entry to `output/entry.txt` (no trailing newline). Node 22+ required, stdlib only, no dependencies, no network access. Running it twice produces a byte-identical file.
